## 📝 Project Overview

This is a **Movie Website** built with **React, Tailwind CSS, and Vite**.  
The website allows users to browse, explore, and interact with movie listings in a modern, responsive UI.  
It is designed for frontend practice and demonstrates **component-based architecture, routing, animations, and responsive layouts**.

---

## 🚀 Tech Stack

- ⚛️ **React 19**  
- 💅 **Tailwind CSS 4**  
- ⚡ **Vite 6**  
- 🎠 **Swiper.js** – Carousel for movies  
- 🔔 **Lucide React & React Icons** – Icons  
- 🧩 **Radix UI** – Accordion & slot components  
- 🎨 **Motion** – Animations  
- 🔗 **React Router 7** – Routing and navigation  
- 🏗️ **Tailwind Merge & clsx** – Utility class management

✅ Responsive UI for desktop and mobile
